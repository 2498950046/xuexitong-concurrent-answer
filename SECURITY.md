# Security Policy

Please do not open public issues that contain passwords, API keys, cookies, private course URLs, screenshots with personal data, or other sensitive information.

If you find a security or privacy problem, use GitHub private vulnerability reporting when available:

https://github.com/2498950046/xuexitong-concurrent-answer/security/advisories/new

Before sharing logs, remove:

- phone numbers
- passwords
- API keys
- cookies
- course URLs with private tokens
- screenshots containing personal or course data

If a secret was committed or pasted publicly, revoke it immediately and generate a new one.
